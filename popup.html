How to Use

  1. Navigate to any Instagram post or reel
  2. Press Alt+I or click the "Extract Data" button
  3. Data will be copied to clipboard automatically
  4. Paste data into your spreadsheet

Output Format

Default format (tab-separated):

URL
Username    Likes    Identified By

Keyboard Shortcuts

  • Alt+I: Extract data from current post
  • Alt+E: Open extension popup

Troubleshooting

If data extraction fails:

  • Make sure you're on an Instagram post or reel page
  • Try refreshing the page
  • Check if Instagram has updated their UI
